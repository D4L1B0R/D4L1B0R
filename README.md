## Featured Project

### GetGo — Full-Stack Ride-Sharing Platform

A comprehensive ride-sharing platform inspired by Uber, developed as a collaborative university project during the fifth semester of the Software Engineering and Information Technologies program (2025/2026).

The project integrated five university courses into a single software development process, covering requirements engineering, system architecture, backend development, frontend development, mobile application development, and software testing.

**System Architecture**

- **Backend:** Java 17, Spring Boot, Spring Security, REST API, JWT authentication.
- **Web Application:** Angular, Angular Material, Leaflet.
- **Mobile Application:** Android SDK, Java, Material Design.
- **Database:** PostgreSQL and H2.
- **Mapping:** OpenStreetMap and Leaflet.

**Key Features**

- Role-based functionality for passengers, drivers, and administrators.
- User registration, email activation, and authentication.
- Ride requests, scheduling, multiple stops, and automatic driver assignment.
- Real-time ride tracking and notifications.
- Interactive maps and route visualization.
- Driver availability management and working-hour restrictions.
- Ride history, filtering, sorting, and rating functionality.
- Administrative monitoring, user management, and reporting.
- Emergency PANIC alert system and live support communication.

**Development Process**

- Collaborative development in a three-member team.
- Agile/Scrum methodology and sprint organization.
- Trello for task management and coordination.
- Git-based version control and team collaboration.
- Integration and testing across backend, web, and mobile components.
